  capability now requires schema 6 because its closed security-evidence types are part of the
  commit contract.
- T016 now replaces the retired global session lifetime with immutable role profiles: Student
  `7d/30d`, Instructor `1h/24h`, and Admin `30m/12h`. General recent authentication defaults to
  `10m`, highest-risk authentication to `5m`, and stale-use classification to `5s`. Invalid,
  non-positive, inverted, or non-binding combinations fail startup; the older global environment
  keys fail loudly instead of silently falling back.
- The T014/T017 domain work has begun with a fail-closed superseded-use classifier. Exactly one
  first ordinary read at or inside the configured stale window returns the replacement outcome;
  repeated, late, future-timestamped, renewal, state-changing, or security-sensitive use selects
  whole-family revocation. Boundary cases pass under the race detector.
- Implementation proved one design gap before repository work: a memory-only CSRF token cannot be
  recovered after reload from a one-way digest alone. Each generation now uses a separately keyed
  HMAC-derived pseudorandom CSRF token, allowing server-only reconstruction from immutable
  generation facts while PostgreSQL retains only its digest. Migration 0006 expands the closed
  Identity security-event allowlist for session creation, renewal, replacement, reuse, and logout;
  it adds no session table or column.
- T014, T015, T017, and T018 are complete. The repository performs current-strength dummy Argon2id
  work for unknown email, co-commits one family/current generation/evidence only for verified Active

  non-rotating, and locks Account/family/generation authority for renewal, logout, and mutation
  rechecks. Real PostgreSQL race tests prove exactly one renewal response wins, confirmed reuse
  revokes that winner's family, logout commits `LOGOUT` evidence before subsequent denial, and
