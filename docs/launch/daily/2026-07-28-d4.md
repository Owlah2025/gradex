- The standing clause applies: a required dependency is validated at construction and the component

## Progress

### M4 — complete

[`specs/005-media-and-entitlement-evaluation/`](../../../specs/005-media-and-entitlement-evaluation/spec.md)
is frozen: spec, plan, research, data model, the delivery contract, 32 tasks, and the quickstart.
**No S4 implementation exists**, which was the acceptance condition.

The plan spends its structure on the two boundaries that make S4 Tier 3, and leaves the pipeline
conventional.

**1. S4 evaluates Entitlements and must never create one.** Guarded four ways rather than by
convention, because conventions failed in S1C and S2 in exactly this shape:

- `internal/entitlement` exports no creation surface — not discouraged, unavailable.
- The seed mechanism sits behind `//go:build !production`, **absent from the production binary**
  rather than disabled within it. A config flag that *could* be flipped in production is not
  exclusion, and this project already holds `AUTH_FAKE_MODE` to that standard.
- A test builds with production constraints and asserts the seed symbol is unreachable — that is the
  defence that survives the next contributor.
- **`source_order_item_id NOT NULL` in the schema**, from this migration, though S7 has not built the
  producer yet. It makes an Entitlement without an Order **unrepresentable**, so neither the seed nor a
  future support script can cheat.

**2. Nothing unscanned is ever reachable.** `LG-014` is unresolved and may stay that way, so the design
question was *what does an unresolved gate degrade?* — and the answer is availability, never safety.
Deliverability is `state == READY`, expressed once. Not an exclusion list: an exclusion list is a place
to forget a state, and a reviewer cannot tell a forgotten exclusion from a deliberate one. There is no
scan outcome meaning "not scanned but proceed", and scanner **absence** leaves assets in `SCANNING`,
which is already non-deliverable.

Two smaller decisions worth naming:

- **The scan result binds to an exact stored object version, not to the logical asset.** A logical
  binding would let a re-upload inherit a previous pass — silent, and the asset is unscanned.
- **Signed access does not promise what it cannot deliver.** An issued presigned URL cannot be revoked;
  the exposure window is bounded by signature lifetime, and the plan says that instead of claiming
  instant revocation. Same class of correction as S3's OD-002.

The slice keeps the calendar's own D7/D8 split — pipeline, then delivery and evaluation — with three
mandatory gates: fail-closed proven **per scanner failure mode individually**, no-creation-path proven
against a production build before any delivery work starts, and denial uniformity across all eight
causes. Ten required mutations are enumerated rather than left to the builder's judgement.
